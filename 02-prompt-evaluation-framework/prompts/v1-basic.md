# Prompt Version 1 — Basic

## Prompt Type
Basic. No examples, no role, no format instructions. Just the raw task.

## Prompt Used

Write an email to a client about a project delay.

## Output Received

Hi,

I wanted to let you know that the project is delayed.
We are working on it and will update you soon.

Sorry for the inconvenience.

Regards

## What Went Wrong

- No new deadline given
- Tone is too casual for a professional email
- Missing proper greeting and sign-off
