## ⚡ Core Skills

### 🎯 Prompt Engineering Techniques
| Technique | Description |
|---|---|
| **Structured Prompting** | Designing clear, role-based prompts with explicit output formats |
| **Few-Shot Prompting** | Guiding model behavior using carefully selected input-output examples |
| **Chain-of-Thought (CoT)** | Breaking complex tasks into step-by-step reasoning chains |
| **Tree-of-Thought (ToT)** | Multi-path reasoning for problems requiring exploration of alternatives |
| **RAG (Retrieval-Augmented Generation)** | Combining external knowledge retrieval with prompt design |
| **Iterative Prompt Development** | Systematic testing, evaluation, and refinement of prompts |

## 📁 Portfolio Projects

> These projects are selected specifically to demonstrate skills most valued in Prompt Engineering internships.

---

### 🥇 Project 1 — Prompt Techniques Showcase
**`/01-prompt-techniques-showcase`**

A structured comparison of 6 prompting techniques applied to the **same real-world task** (e.g., customer complaint classification). Includes zero-shot, few-shot, CoT, ToT, structured, and role-based approaches — each with output comparisons and a quality analysis.

**Why it matters for hiring:** Shows interviewers you don't just know the names — you know *when and why* to use each technique.

**Stack:** Python · OpenAI / Anthropic API · Jupyter Notebook  
**Key Files:** `prompts/`, `outputs/`, `analysis.md`

---

### 🥇 Project 2 — Prompt A/B Testing & Evaluation Framework
**`/02-prompt-evaluation-framework`**

A mini evaluation system where I test multiple versions of a prompt on the same task, score outputs using a rubric (accuracy, tone, format, completeness), and present results in a report. Includes LLM-as-judge methodology.

**Why it matters for hiring:** Evaluation is one of the most in-demand skills at AI companies. This project proves you think like a prompt engineer, not just a prompt writer.

**Stack:** Python · Pandas · Jupyter Notebook  
**Key Files:** `eval_rubric.md`, `results/`, `notebook.ipynb`

---

### 🥇 Project 3 — RAG-Based Q&A System
**`/03-rag-qa-system`**

A Retrieval-Augmented Generation pipeline where a user can ask questions about a custom document (PDF/text). Prompts are engineered to handle retrieved context gracefully — including cases where context is missing or contradictory.

**Why it matters for hiring:** RAG is the dominant architecture in enterprise AI. Building and prompting a RAG pipeline is a top skill listed in internship JDs.

**Stack:** Python · LangChain · FAISS · OpenAI API  
**Key Files:** `rag_pipeline.py`, `prompts/system_prompt.md`, `demo.ipynb`

---

### 🥇 Project 4 — Structured Output Extractor
**`/04-structured-output-extractor`**

Prompts designed to extract clean, validated JSON from messy unstructured text (resumes, invoices, news articles). Includes schema enforcement, error handling for malformed outputs, and retry logic.

**Why it matters for hiring:** Structured outputs are used in almost every real AI product. This shows you can connect LLMs to actual systems.

**Stack:** Python · Pydantic · OpenAI API  
**Key Files:** `extractor.py`, `schemas/`, `test_cases/`

---

### 🥇 Project 5 — Domain Chatbot with System Prompt Architecture
**`/05-domain-chatbot`**

A chatbot built for a specific domain (e.g., HR FAQ, study assistant, or e-commerce helper). The focus is on the **system prompt design** — persona, guardrails, tone, memory management, and graceful fallback behavior.

**Why it matters for hiring:** Building real chatbots is the most common internship task. This proves you can do it end-to-end.

**Stack:** Python · Streamlit · Anthropic / OpenAI API  
**Key Files:** `system_prompt.md`, `app.py`, `README.md`

---

### 🥇 Project 6 — Chain-of-Thought vs Direct Prompting: Case Study
**`/06-cot-case-study`**

A documented case study comparing direct prompting vs CoT prompting on 10 reasoning tasks (math, logic, multi-step decisions). Includes a before/after analysis showing *why* CoT improved results, with failure cases included.

**Why it matters for hiring:** This is the kind of analytical write-up that impresses technical hiring managers. It shows depth, not just breadth.

**Stack:** Python · Jupyter Notebook · Markdown  
**Key Files:** `case_study.md`, `experiments/`, `results_summary.md`
