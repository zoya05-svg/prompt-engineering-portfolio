## 📁 Portfolio Projects

---

### 🥇 Project 1 — Prompt Techniques Showcase

A structured comparison of 6 prompting techniques applied to the same real-world task: customer complaint classification. Includes zero-shot, few-shot, CoT, ToT, structured, and role-based approaches with output comparisons and quality analysis.

**Why it matters for hiring:** Shows interviewers you do not just know the names. You know when and why to use each technique.

**Stack:** Python · OpenAI / Anthropic API · Jupyter Notebook

| File | Description |
|---|---|
| prompts/01-zero-shot.md | No examples given to the model |
| prompts/02-few-shot.md | 3 examples given before the task |
| prompts/03-chain-of-thought.md | Model reasons step by step |
| prompts/04-tree-of-thought.md | Model explores multiple paths |
| prompts/05-structured.md | Output forced into JSON format |
| prompts/06-role-based.md | Model given a persona |
| outputs/comparison-table.md | All outputs compared side by side |
| analysis.md | Full written analysis of findings |

---

### 🥇 Project 2 — Prompt A/B Testing and Evaluation Framework

A mini evaluation system where I test multiple versions of a prompt on the same task, score outputs using a rubric covering accuracy, tone, format, and completeness, and present results in a structured report. Includes LLM-as-judge methodology.

**Why it matters for hiring:** Evaluation is one of the most in-demand skills at AI companies. This project proves I think like a prompt engineer, not just a prompt writer.

**Stack:** Python · Pandas · Jupyter Notebook

| File | Description |
|---|---|
| eval_rubric.md | The scoring rubric used to judge all outputs |
| prompts/v1-basic.md | Version 1 of the prompt — no guidance |
| prompts/v3-structured.md | Version 3 — structured checklist prompt |
| results/scores-table.md | All scores compared in one table |
| results/winner-analysis.md | Which prompt won and why |
